# Данные программы, проектов и контактов

Фронтенд отображает значения из API. Заполните данные в CMS и проверьте, что API отдаёт их в ответах для сайта.

## 1. Темы мероприятий на главной

В `POST /api/getProgramSummary` передавайте `programTopic` в каждом элементе `days[].rooms[].events[]`, где в CMS указана тема. Это строка на языке запроса (`lang: "ru"` или `lang: "en"`). Для события без темы поле можно опустить или передать `null`.

Фрагмент события из английской программы:

```json
{
  "title": "Public talk",
  "programTopic": "Microdramas: The new black or a hot trend?"
}
```

Проверьте дискуссии и презентации за `2026-12-03` в обеих локалях. На главной в разделе «Программа» тема должна появиться под названием соответствующего события.

## 2. Хронометраж The Steel Family

В ответе `POST /api/getProject` передавайте на верхнем уровне массив `durations`. У каждой записи есть непустой `label`, положительное число `lengthMinutes` и положительное целое `episodes` для сезона. Для фильма передайте `episodes: null` или опустите поле.

```json
{
  "durations": [
    { "label": "Season 1", "episodes": 11, "lengthMinutes": 22 },
    { "label": "Season 2", "episodes": 10, "lengthMinutes": 20 },
    { "label": "Feature film", "episodes": null, "lengthMinutes": 101 }
  ]
}
```

Карточка показывает строки в порядке массива. Если массив отсутствует или пуст, карточка использует одиночный хронометраж из верхнеуровневых `lengthMinutes` и `episodes`.

## 3. Годы производства

Запишите в CMS диапазоны **Technolike — `2024-2025`**, **The Steel Family — `2026-2027`**. В JSON передавайте диапазон строкой в поле `year`, например `"year": "2024-2025"`. Одиночный год по-прежнему можно передавать числом.

Проверьте согласованность `year` в `getProject`, `getProjects` (`items[]`), `getParticipant` и `getProgramEvent` (`projects[]` в обоих ответах).

## 4. Две почты представителя компании

В `POST /api/getParticipant` передавайте адреса в массиве `contact.emails`. Используйте отдельный валидный email для каждого элемента. Остальные поля контакта сохраняются. Пример с условными адресами:

```json
{
  "contact": {
    "name": "Arseny Ovchinnikov",
    "position": "Producer",
    "emails": ["first@example.org", "second@example.org"]
  }
}
```

В карточке компании под должностью появятся две ссылки в порядке массива. Для старой записи с одним адресом поддерживается `contact.email`, если поле `contact.emails` отсутствует. Пустой массив означает, что ссылки выводить не нужно.
